# Arbitrary Waveform Generator with Timer-based DMA

## Description
Uses a timer trigger and DMA to feed a waveform table to the DAC at a fixed sample rate.

## Hardware
- NUCLEO-F446RE
- Oscilloscope
- Jumper wire from PA4
