# ADC with Multiple Inputs - Polling ADC

## Description
Reads two analogue channels and displays both measured voltages.

## Hardware
- NUCLEO-F446RE
- 16x2 LCD
- 2 x 10 kohm potentiometers or 0-3.3 V sources
- Breadboard and jumper wires
