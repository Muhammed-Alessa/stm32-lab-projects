# FreeRTOS - Three LED Tasks

## Description
Creates three RTOS tasks that blink three LEDs at different rates to demonstrate multitasking.

## Hardware
- NUCLEO-F446RE
- 3 LEDs
- 3 x 330-470 ohm resistors
- Breadboard and jumper wires
