# Analogue Voltmeter - Polling ADC

## Description
Samples one analogue input with ADC1 in polling mode and converts the reading to millivolts.

## Hardware
- NUCLEO-F446RE
- 16x2 LCD
- 10 kohm potentiometer or 0-3.3 V analogue source
- Breadboard and jumper wires
