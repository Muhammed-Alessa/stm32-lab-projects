# ON-OFF Temperature Controller

## Description
Compares a TMP36 temperature reading with a setpoint and switches a low-voltage indicator output on or off.

## Hardware
- NUCLEO-F446RE
- TMP36 temperature sensor
- 16x2 LCD
- LED and 330 ohm resistor or low-voltage relay module
- Breadboard and jumper wires
