# I2C Port Expander

## Description
Controls an LED connected to an MCP23017 port expander by writing its registers over I2C.

## Hardware
- NUCLEO-F446RE
- MCP23017
- LED
- 330 ohm resistor
- 2 x 4.7-10 kohm pull-ups
- Breadboard and jumper wires
