# Single-input ADC with Conversion Interrupt

## Description
Starts an ADC conversion and handles the completed sample in the ADC interrupt callback.

## Hardware
- NUCLEO-F446RE
- 16x2 LCD
- 10 kohm potentiometer or 0-3.3 V source
- Breadboard and jumper wires
