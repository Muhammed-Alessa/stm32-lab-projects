# Using LCDs - Simple Up Counter

## Description
Counts upward once per second and displays the value on a character LCD.

## Hardware
- NUCLEO-F446RE
- 16x2 HD44780-compatible LCD
- 10 kohm contrast potentiometer
- Breadboard and jumper wires
