# Standby Mode Example

## Description
Enters Standby mode and demonstrates wake-up behavior using a supported wake-up input.

## Hardware
- NUCLEO-F446RE
- Pushbutton on PA0/A0
- On-board LD2 LED
- Breadboard and jumper wires
