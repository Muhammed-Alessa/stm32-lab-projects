# Multiple-input ADC with DMA

## Description
Continuously samples two ADC channels and transfers the results to memory with DMA.

## Hardware
- NUCLEO-F446RE
- 16x2 LCD
- 2 x 10 kohm potentiometers or 0-3.3 V sources
- Breadboard and jumper wires
