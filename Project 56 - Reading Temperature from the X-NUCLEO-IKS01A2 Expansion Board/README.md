# Reading Temperature from the X-NUCLEO-IKS01A2 Expansion Board

## Description
Reads environmental temperature data from the X-NUCLEO-IKS01A2 and reports it over USART2.

## Hardware
- NUCLEO-F446RE
- X-NUCLEO-IKS01A2
- USB cable
