# Two-digit Interrupt-Driven 7-Segment Event Counter

## Description
Counts button events with an interrupt and shows the count on a multiplexed two-digit display.

## Hardware
- NUCLEO-F446RE
- 2-digit common-cathode 7-segment display
- 7 x 330-470 ohm resistors
- 2 NPN transistors
- Pushbutton
- Breadboard and jumper wires
