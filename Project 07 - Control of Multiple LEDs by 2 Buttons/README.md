# Control of Multiple LEDs by 2 Buttons

## Description
Uses two buttons to move the lit LED left or right across an eight-LED row.

## Hardware
- NUCLEO-F446RE
- 8 LEDs
- 8 x 470 ohm resistors
- 2 pushbuttons
- Breadboard and jumper wires
