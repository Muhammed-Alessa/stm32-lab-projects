# Interrupt-Based Up-Down Counter with Four-Digit 7-Segment LED Display

## Description
Uses two interrupt-driven buttons to increment or decrement a value shown on a four-digit display.

## Hardware
- NUCLEO-F446RE
- 4-digit common-cathode 7-segment display
- 2 pushbuttons
- 4 NPN transistors
- Resistors
- Breadboard and jumper wires
