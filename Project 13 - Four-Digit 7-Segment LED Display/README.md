# Four-Digit 7-Segment LED Display

## Description
Multiplexes four 7-segment digits and displays a fixed four-digit value.

## Hardware
- NUCLEO-F446RE
- 4-digit common-cathode 7-segment display
- 7 x 330-470 ohm resistors
- 4 NPN transistors
- Breadboard and jumper wires
