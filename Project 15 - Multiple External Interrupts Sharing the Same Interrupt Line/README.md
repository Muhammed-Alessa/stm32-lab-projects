# Multiple External Interrupts Sharing the Same Interrupt Line

## Description
Demonstrates how GPIO interrupt sources sharing one NVIC handler can be distinguished in software.

## Hardware
- NUCLEO-F446RE
- 2 pushbuttons
- On-board LD2 LED
- Breadboard and jumper wires
