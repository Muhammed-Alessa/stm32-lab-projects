# Two-Digit Multiplexed 7-Segment LED

## Description
Multiplexes two digits so a two-digit number appears continuously while sharing the segment lines.

## Hardware
- NUCLEO-F446RE
- 2-digit common-cathode 7-segment display
- 7 x 330-470 ohm resistors
- 2 NPN transistors
- Breadboard and jumper wires
