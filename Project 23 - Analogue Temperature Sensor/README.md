# Analogue Temperature Sensor

## Description
Measures a TMP36 analogue temperature sensor and converts its voltage to degrees Celsius.

## Hardware
- NUCLEO-F446RE
- TMP36 temperature sensor
- 16x2 LCD
- Breadboard and jumper wires
