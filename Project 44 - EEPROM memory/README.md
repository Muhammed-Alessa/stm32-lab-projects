# EEPROM memory

## Description
Writes bytes to a 24LC256 I2C EEPROM, reads them back, and uses the recovered value in the application.

## Hardware
- NUCLEO-F446RE
- 24LC256 EEPROM
- 2 x 4.7-10 kohm pull-ups
- Breadboard and jumper wires
