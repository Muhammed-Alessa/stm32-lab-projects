# 7-Segment LED Counter

## Description
Counts from 0 to 9 and displays each number on a single common-cathode 7-segment display.

## Hardware
- NUCLEO-F446RE
- 1-digit common-cathode 7-segment display
- 7 x 330-470 ohm resistors
- Breadboard and jumper wires
