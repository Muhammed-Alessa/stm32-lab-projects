# 4-Digit 7-Segment LED Up Counter with Timer Interrupts

## Description
Refreshes a four-digit display from a timer interrupt while the main application updates the count.

## Hardware
- NUCLEO-F446RE
- 4-digit common-cathode 7-segment display
- 4 NPN transistors
- Resistors
- Breadboard and jumper wires
