# Using parallel LCDs - Displaying Text

## Description
Interfaces an HD44780-compatible character LCD in 4-bit mode and displays a short message.

## Hardware
- NUCLEO-F446RE
- 16x2 HD44780-compatible LCD
- 10 kohm contrast potentiometer
- Breadboard and jumper wires
