# Communicating with Arduino - Displaying Temperature

## Description
Receives temperature data over a UART link from a second microcontroller and forwards it to the PC terminal.

## Hardware
- NUCLEO-F446RE
- Second 3.3 V-compatible UART device or properly level-shifted board
- Jumper wires
- USB cable
