# TMP102 Temperature Sensor Chip Reading

## Description
Reads the TMP102 temperature register over I2C and sends the converted value to the PC.

## Hardware
- NUCLEO-F446RE
- TMP102 breakout/module
- USB cable
- Breadboard and jumper wires
