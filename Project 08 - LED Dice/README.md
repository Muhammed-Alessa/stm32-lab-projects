# LED Dice

## Description
Generates a value from 1 to 6 when the button is pressed and shows it using seven LEDs arranged like a dice face.

## Hardware
- NUCLEO-F446RE
- 7 LEDs
- 7 x 470 ohm resistors
- On-board user button
- Breadboard and jumper wires
