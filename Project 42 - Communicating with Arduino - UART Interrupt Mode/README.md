# Communicating with Arduino - UART Interrupt Mode

## Description
Receives UART data using interrupts instead of blocking polling.

## Hardware
- NUCLEO-F446RE
- Second 3.3 V-compatible UART device or properly level-shifted board
- Jumper wires
- USB cable
