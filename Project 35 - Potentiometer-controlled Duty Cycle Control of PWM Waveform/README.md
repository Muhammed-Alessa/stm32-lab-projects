# Potentiometer-controlled Duty Cycle Control of PWM Waveform

## Description
Reads a potentiometer with the ADC and maps the value to PWM duty cycle.

## Hardware
- NUCLEO-F446RE
- 10 kohm potentiometer
- Oscilloscope or LED with resistor
- Breadboard and jumper wires
