# Displaying Ambient Temperature on the PC Screen

## Description
Measures a TMP36 sensor once per second and sends the temperature to the PC through USART2.

## Hardware
- NUCLEO-F446RE
- TMP36 temperature sensor
- USB cable
- Breadboard and jumper wires
